# TravelMate 匿名质量评分包

每个样本只展示 `sample_id`、用户输入、最终行程与预算，不展示模型、运行序号、Trace ID 或其他评审者意见。

## 评分维度

对每项独立给出 1–5 分：可执行性、个性化、完整性、表达清晰度、安全性。

## 复核规则

- 两名评审独立评分，不共享评分结果。
- 任一维度分差超过 1 分时进入复核；复核记录保留原始双评分与最终结论。
- 评分包中的原始 artifact 路径仅供管理员保留，不能展示给评审。
