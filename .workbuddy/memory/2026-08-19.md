## traces/{id}/summary 返回 50001 根因
- 现象：GET /api/v1/traces/trc_20260819_23e74a893bfe/summary 返回业务码 50001（未捕获系统内部错误）。
- 根因：该 trace 在 tracing.db 的 `spans` 表有 `span_type='外部api'` 的记录（共 18 条，来自 src/services/map.py 记录地图外部调用）。summary 接口 traces.py:276 构造 `SpanSummaryItem` 时，模型 `SpanType = Literal["llm","io","function","workflow"]`（src/models/traces.py:16）不含 `外部api`，触发 Pydantic `ValidationError`。该异常非 AppException/RequestValidationError，被 exceptions.py:243 通用 Exception 处理器兜成 50001。
- 影响面：`get_trace_detail`（SpanDetailItem.span_type 同 Literal）对含 外部api 的 trace 同样会 50001。前端 api/traces.ts 的 SPAN_TYPE_LABELS 也未含 外部api（会原样显示中文，可接受）。
- 修复方向（未落代码，用户要"分析为主"）：在 SpanType Literal 追加 `"外部api"`（推荐）；或把模型字段放宽成 str。复现已确认：直接调用 get_trace_summary 抛 `ValidationError: span_type Input should be 'llm','io','function' or 'workflow' [input_value='外部api']`。

## 行程定价架构落地（方法1-4：enrich 唯一定价）
- 背景：原来 `ItineraryItem` 无 cost 字段，行程小项价格全 0；Budget Agent 用 LLM 拍脑袋算总额，且 budget.detail 只有 transport/hotel/food/tickets 类目总额、无逐日/逐笔。
- 方案：LLM 只管行程骨架（不写 cost），`cost_enrich` 成为唯一确定性定价方，Budget Agent 退化为「Σ(item.cost+leg_transport_cost) 翻转成 detail」。
- 改动文件（已落地，py_compile 通过）：
  - `graph/state.py`：`ItineraryItem` 增 `cost/cost_category/poi_ref/location/leg_transport_cost`（全 Optional，前端兼容）。
  - `services/map.py`：新增 `amap_distance_km`（v3/distance 驾车距离）+ `fetch_food_pois_with_cache`（keywords=美食，补全餐饮单价覆盖）。新增 `import re`。
  - `agents/cost_enrich.py`（新建）：`enrich_itinerary_costs` —— 方法1 POI 精确/子串匹配写真实单价（×travelers）；方法2 相邻 item 距离×主交通方式费率写 `leg_transport_cost`；方法3 无匹配按 budget_level 估算餐费/门票。费率表：TRANSPORT_RATE_PER_KM、FOOD_PER_MEAL、TICKET_PER_ATTRACTION。
  - `agents/itinerary_agent.py`：导入 enrich；PLAN 与 REPLAN 分支在 `_ensure_itinerary_image_urls` 后调用 `enrich_itinerary_costs`；`_normalize_item` 透传新字段。
  - `agents/budget_agent.py`：删 `_normalize_budget/_normalize_detail/_as_non_negative_float` 与 `BudgetDetail` 导入；新增 `_flip_budget_from_items`（food/tickets 取 item.cost 汇总、transport 取 leg_transport_cost 汇总、hotel 按晚数×等级估算为行程级变量，不在每日 item）；LLM 只出 level+saving_tips。
- 关键决策（用户确认）：①住宿行程级（整趟同酒店），不进每日 item，只在 budget.detail.hotel 估算；②cost 直接存 ×travelers 总额；③可接受多用一次高德配额抓美食 POI；④transport 腿费挂 `leg_transport_cost` 在到达 item，不合成独立 transport item。
- 注意：高德 `biz_ext.cost` 可能为中文「人均XX」/None，`_parse_amap_cost` 已做正则提取；无坐标的 item 交通腿费记 0。
