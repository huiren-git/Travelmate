## GET 获取完整行程快照

GET /api/v1/sessions/{session_id}/snapshot

获取指定会话的完整状态快照（Checkpoint）。
包含该次 Agent 执行过程中的完整 DAG 节点状态、任务清单（Task List）、黑板（Blackboard）数据、工具调用记录以及 LLM 上下文摘要。
用于前端展示完整执行轨迹或实现“断点续跑”的现场恢复。

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|session_id|path|string| 是 |会话唯一标识符（通常对应 LangGraph 的 thread_id）|
|include_raw_traces|query|boolean| 否 |是否包含原始的 LLM 请求/响应日志（默认 false，因数据量较大）|

> 返回示例

> 200 Response

```json
{
  "session_id": "string",
  "state": {
    "task_list": [
      {
        "id": "t1",
        "status": "done",
        "output": 1000
      }
    ],
    "blackboard": {
      "root_cause": "数据库超时"
    }
  },
  "graph_structure": {
    "nodes": [
      "string"
    ],
    "edges": [
      {
        "from": "string",
        "to": "string"
      }
    ]
  },
  "metadata": {
    "total_llm_calls": 0,
    "total_tokens_consumed": 0,
    "trace_logs": [
      "string"
    ]
  },
  "created_at": "2019-08-24T14:15:22Z"
}
```

### 返回结果

|状态码|状态码含义|说明|数据模型|
|---|---|---|---|
|200|[OK](https://tools.ietf.org/html/rfc7231#section-6.3.1)|成功返回会话快照数据|[SessionSnapshot](#schemasessionsnapshot)|
|404|[Not Found](https://tools.ietf.org/html/rfc7231#section-6.5.4)|指定的会话 ID 不存在或已过期（TTL 超时）|[ErrorResponse](#schemaerrorresponse)|

## GET 获取历史会话列表

GET /api/v1/sessions

返回当前用户的历史行程会话，按更新时间倒序排列。

采用**基于时间游标的分页**，前端滚动到底部时，使用返回的 `next_cursor` 继续加载。
- 首次请求：不传 `cursor`
- 后续请求：传入上次响应中的 `next_cursor`
- `has_more: false` 表示已全部加载完毕

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|limit|query|integer| 否 |每页返回条数（默认 20，最大 50）|
|cursor|query|string(date-time)| 否 |游标，值为上一页返回的 `next_cursor`（ISO 8601 时间格式）。|
|X-User-Id|header|string| 是 |用户标识（开发阶段使用，后续升级为 Token）|

#### 详细说明

**cursor**: 游标，值为上一页返回的 `next_cursor`（ISO 8601 时间格式）。
首次请求不传此参数。

## DELETE 删除行程记录

DELETE /api/v1/sessions/{session_id}

逻辑删除指定会话的所有历史记录。
用户语义偏好：引用计数-1
记录用户操作日志。

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|session_id|path|string| 是 |要删除的会话 ID|

> 返回示例

> 404 Response

```json
{
  "code": 40101,
  "message": "身份验证失败",
  "details": {
    "field": "limit",
    "error": "limit 不能超过 50"
  }
}
```

### 返回结果

|状态码|状态码含义|说明|数据模型|
|---|---|---|---|
|204|[No Content](https://tools.ietf.org/html/rfc7231#section-6.3.5)|删除成功（无内容返回）|None|
|404|[Not Found](https://tools.ietf.org/html/rfc7231#section-6.5.4)|会话不存在|[ErrorResponse](#schemaerrorresponse)|
|409|[Conflict](https://tools.ietf.org/html/rfc7231#section-6.5.8)|删除冲突（如会话正在运行中，无法删除）|[ErrorResponse](#schemaerrorresponse)|
