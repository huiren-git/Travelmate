## GET 获取 Trace 列表

GET /api/v1/traces

返回所有追踪记录（Traces），支持时间、会话、用户、状态筛选，并按时间倒序分页返回。
聚合了每个 Trace 的 Span 数量，并计算总耗时。

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|start_time|query|string(date-time)| 否 |筛选开始时间（包含），ISO 8601 格式|
|end_time|query|string(date-time)| 否 |筛选结束时间（包含），ISO 8601 格式|
|thread_id|query|string| 否 |会话 ID 精确匹配|
|user_id|query|string| 否 |用户 ID 精确匹配|
|status|query|string| 否 |追踪状态|
|page|query|integer| 否 |页码（从 1 开始）|
|limit|query|integer| 否 |每页条数（最大 100）|

#### 枚举值

|属性|值|
|---|---|
|status|running|
|status|success|
|status|error|
|status|cancelled|

> 返回示例

> 200 Response

```json
{
    "code": 200,
    "data": {
        "traces": [
            {
                "trace_id": "trc_20260817_a1b2c3",
                "thread_id": "thr_8h4k2m9xq3w1",
                "user_id": "user_123",
                "input_message": "帮我规划北京3日游",
                "start_time": "2026-08-17T10:00:00Z",
                "end_time": "2026-08-17T10:00:08Z",
```

业务错误码，5 位数字。分类如下：

**系统/服务错误 (50000-50999)**
- 50001: 服务器内部错误
- 50301: AI 服务不可用
- 50302: 数据服务异常

**认证/权限错误 (40100-40399)**
- 40101: 缺少用户身份标识
- 40102: Token 无效或已过期
- 40301: 无权操作该资源

**客户端参数错误 (40000-40099)**
- 40002: 请求参数校验失败
- 40003: 参数类型或枚举值错误
- 40004: 预算下限不能高于上限
- 40005: 修改操作缺少具体指令
- 40006: 决策类型无效
- 40007: 添加偏好缺少内容

**资源不存在 (40400-40499)**
- 40401: 会话不存在或已过期
- 40402: 行程快照不存在
- 40403: 用户偏好标签不存在

**流程冲突 (40900-40999)**
- 40901: 当前会话不在中断状态

**数据校验错误 (42200-42299)**
- 42201: 行程景点图片不存在或不可用
