## GET 获取用户偏好标签

GET /api/v1/users/me/preferences

返回当前用户的所有偏好标签，按置信度降序排列。

**数据来源**：
- 系统自动提取：从用户对话中通过语义分析提取的偏好（如“我喜欢市井烟火气”）
- 用户手动设置：用户通过此接口主动添加或修改的偏好

**使用场景**：
- 用户在“个人中心”查看自己的偏好画像
- 用户发现系统提取的偏好不准确时，手动修正或删除

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|category|query|string| 否 |按类别筛选（可选）|
|include_inferred|query|boolean| 否 |是否包含系统推断的偏好（默认 true）|
|X-User-Id|header|string| 是 |用户标识（开发阶段使用，后续升级为 Token）|

#### 枚举值

|属性|值|
|---|---|
|category|diet|
|category|pace|
|category|budget|
|category|interest|
|category|accommodation|
|category|transport|

## POST 添加偏好标签

POST /api/v1/users/me/preferences

用户手动添加一条新的偏好标签，如“不吃海鲜”

> Body 请求参数

```json
{
  "category": "diet",
  "content": "不吃海鲜"
}
```

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|X-User-Id|header|string| 是 |none|
|body|body|object| 是 |none|
|» category|body|string| 是 |none|
|» content|body|string| 是 |偏好的自然语言描述|

#### 枚举值

|属性|值|
|---|---|
|» category|diet|
|» category|pace|
|» category|budget|
|» category|interest|
|» category|accommodation|
|» category|transport|

## PUT 修改偏好标签

PUT /api/v1/users/me/preferences/{id}

全量更新指定偏好标签的内容

> Body 请求参数

```json
{
  "content": "喜欢吃辣，特别偏爱重庆火锅"
}
```

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|id|path|string| 是 |偏好标签 ID|
|X-User-Id|header|string| 是 |none|
|body|body|object| 是 |none|
|» content|body|string| 是 |更新后的内容|

> 返回示例

> 200 Response

    "message": "偏好已更新",

## DELETE 删除偏好标签

DELETE /api/v1/users/me/preferences/{id}

软删除指定偏好标签，数据保留但标记为失效

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|id|path|string| 是 |偏好标签 ID|
|X-User-Id|header|string| 是 |none|

> 返回示例

> 200 Response

```json
{
    "code": 200,
    "message": "偏好已删除",
    "data": {
        "id": "pref_004",
        "is_active": false,
        "deleted_at": "2026-08-04T10:10:00Z"
    }
}
```

### 返回结果

|状态码|状态码含义|说明|数据模型|
|---|---|---|---|
|200|[OK](https://tools.ietf.org/html/rfc7231#section-6.3.1)|删除成功|Inline|
|401|[Unauthorized](https://tools.ietf.org/html/rfc7235#section-3.1)|身份验证失败|None|
|403|[Forbidden](https://tools.ietf.org/html/rfc7231#section-6.5.3)|无权操作该偏好|None|
