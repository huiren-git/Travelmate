### 💡 特别提醒（避坑指南）

1.  **关于 LLM 异步存储**：在 `agents/base.py` 中记录 LLM 事件时，不要 `await` 等待数据库写入完成，否则会增加每次 LLM 调用的延迟。使用 `asyncio.create_task(log_llm_event(...))` 将写入操作异步化。
2.  **数据膨胀问题**：`llm_events.response_text` 可能很大（如完整的行程 JSON 高达 10KB）。在数据库层面字段类型用 `TEXT`，前端展示时默认折叠。
3.  **复用现有 SQLite 连接**：你已经在 `graph.py` 中用了 `SqliteSaver`，注意不要让 Tracing 模块创建新的连接池，共享同一个 SQLite 连接，避免锁竞争。
