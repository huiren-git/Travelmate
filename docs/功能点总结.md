### 一、AI 对话中枢（Chat Center）

| 序号 | 功能点             | 功能描述                                                     | 状态     | 备注               |
| :--- | :----------------- | :----------------------------------------------------------- | :------- | :----------------- |
| 1.1  | **自然语言对话**   | 支持多轮自由对话，用户可直接用自然语言描述需求               | 🔴 未开始 | 核心入口           |
| 1.2  | **意图模糊澄清**   | 当用户需求不完整时（如只说“想去个凉快的地方”），Agent 主动反问关键信息 | 🔴 未开始 | 体现“智能感”       |
| 1.3  | **结构化表单输入** | 用户可通过表单快速填写目的地、天数、预算、偏好等，与自然语言并行 | 🔴 未开始 | 提升关键信息填写率 |

| 1.5  | **思考过程可视化** | 前端实时展示 Supervisor 的调度日志（如“正在查询天气...”）    | 🔴 未开始 | 让 Agent 白盒化    |
| 1.6  | **打断/停止生成**  | 用户可随时点击“停止”按钮中断过长的生成流程                   | 🔴 未开始 | 用户控制权         |
| 1.7  | **人机协同中断**   | 关键决策点（如预算超支）暂停流程，等待用户确认或修改后继续   | 🔴 未开始 | 项目差异化亮点     |

### 二、行前智能规划（Pre-trip Planning）

| 序号 | 功能点               | 功能描述                                                     | 状态     | 备注               |
| :--- | :------------------- | :----------------------------------------------------------- | :------- | :----------------- |
| 2.1  | **数据预取节点**     | 在 Agent 规划前，并发调用外部 API 获取天气、景点列表等实时数据 | 🔴 未开始 | 纯异步函数，非LLM  |
| 2.2  | **智能行程生成**     | 基于目的地、天数、预算、偏好、同行人等信息，自动生成日度行程单 | 🔴 未开始 | 核心 Agent         |
| 2.3  | **增量式动态修改**   | 旅行中用户提出变更需求时，仅修改未来行程，已完成的行程保持不变 | 🔴 未开始 | 项目核心差异化亮点 |
| 2.4  | **预算智能核算**     | 根据行程自动估算机酒、门票、餐饮、交通等费用，并给出省钱建议 | 🔴 未开始 | 辅助 Agent         |
| 2.5  | **Harness 方案校验** | 硬规则（代码）+ 软评估（轻量级LLM）双通道校验，确保方案质量  | 🔴 未开始 | 质量门禁           |
| 2.6  | **有限重试机制**     | 校验失败后自动修正，最多重试3次，防止死循环                  | 🔴 未开始 | 工程稳健性         |
| 2.7  | **多方案比选**       | 生成 2-3 套不同风格的行程方案（如紧凑版/轻松版），让用户选择 | ⚪ 规划中 | 后续迭代           |
