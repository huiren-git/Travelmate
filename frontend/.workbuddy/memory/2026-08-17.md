## 项目约定与坑（重要）
- antd 实际版本 v6.5.3；表格列类型用 `TableProps<T>['columns']`（从 'antd' 导入），不要用 `antd/es/table` 深路径（v6 下不稳）。
- `dayjs` 不是直接依赖（仅 antd 传递依赖）；日期筛选用了原生 `datetime-local` 输入以避免版本耦合。
- `vite build` 在本机会因 `emptyDir`(safe-delete) 清空 `dist` 失败报错；验证构建请用 `--outDir dist_check` 之类的全新目录，别动 dist。
- 页面结构约定：pages/ 组件 → layouts/ Layout → hooks/useXPageData → store/api 数据；需要顶部 Header 的页面用 `withAppLayout` 包裹。
- 主题色用 `travelmateTheme`（src/utils/theme.tsx），状态 Tag 参照 StatusTags 的 rounded-full + bg-*-50 + text-*-600 风格。
