# 2026-08-19

## 修复：/chat 右边栏行程卡片餐具占位图偏左

- 文件：`src/components/common/ItineraryImage.tsx` 的 `CutleryPlaceholder` div。
- 根因：antd v6 通过 CSS-in-JS 在运行时注入 `.ant-card-cover > * { display: block; width: 100% }`，该规则与 Tailwind 的 `flex` 工具类特异性相同 (0,1,0)，但注入顺序更靠后 → 覆盖 `display:flex`，导致 `justify-center`/`items-center` 失效，内联 `<svg>` 在满宽 cover 内靠左对齐。
- 占位 SVG 几何本身居中（实测 viewBox 内 bbox 中心偏移 dx=1.1 / dy=-0.9，可忽略），排除图标路径问题。
- 修复：把占位 div 的 `flex` 改为 `!flex`（Tailwind v4 重要修饰符 → `display: flex !important`），强制覆盖 antd 的 `display:block`，恢复水平/垂直居中。仅作用于占位 div，不影响 `<img>` 分支（img 用 `w-full object-cover` 满宽显示，本就正常）。
- 经验：antd Card `cover` 子元素会被强制 `display:block`，凡把 flex/grid 容器作为 cover 直接子节点都需用 `!flex`/`!grid` 兜底。
